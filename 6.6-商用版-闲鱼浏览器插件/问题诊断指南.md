## 🧪 测试步骤

### 步骤 1：重新加载插件

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 找到"闲鱼数据采集助手"
4. 点击刷新图标 🔄
5. 确认版本号是 `5.3.50`

### 步骤 2：清除旧缓存（可选）

如果之前有损坏的缓存，请清除：

1. 在 `chrome://extensions/` 页面
2. 点击插件的"详细信息"
3. 滚动到底部，点击"清除存储"
4. 或者，在控制台执行（后续步骤会用到）：
```javascript
chrome.storage.local.remove(['excelJSCache'], () => {
    console.log('缓存已清除');
});
```

### 步骤 3：打开开发者工具

**这一步非常重要！**

1. 在 Chrome 访问 `chrome://extensions/`
2. 开启"开发者模式"（右上角开关）
3. 找到"闲鱼数据采集助手"
4. 点击"service worker"链接（或"背景页"）
5. 这会打开一个新窗口，显示 background.js 的控制台

**保持这个控制台窗口打开！** 所有的调试日志都会在这里显示。

4. 点击"开始采集"
5. 等待采集完成

## 📋 问题诊断清单

### 情况 1：第一次使用失败（无缓存）

**期望行为**：尝试从3个 CDN 下载 ExcelJS

**可能原因**：
- ❌ 网络连接问题
- ❌ 防火墙/代理阻止了 CDN 访问
- ❌ DNS 解析问题

**解决方案**：
1. 检查网络连接
2. 尝试访问 https://cdn.jsdelivr.net （看是否能打开）
3. 如果在公司网络，可能需要配置代理
4. 切换到其他网络（如手机热点）试试

### 情况 2：有缓存但加载失败

**错误日志示例**：
```
[导出] 从缓存加载ExcelJS，大小: 1234567
[导出] 缓存的ExcelJS无效，将重新下载: ...
```

**解决方案**：
1. 清除缓存（执行步骤2）
2. 重新尝试导出

### 情况 3：加载成功但生成失败

**错误日志示例**：
```
[导出] ✅ ExcelJS库加载成功
...
[导出] ❌❌❌ Excel生成失败，回退到CSV ❌❌❌
[导出] 错误信息: ...
```

**将错误信息发给我**，我会帮您解决！

## 🛠️ 紧急解决方案

### 方案 A：手动下载ExcelJS并缓存

如果所有 CDN 都无法访问，可以手动下载并缓存：

1. 从以下任一URL下载 exceljs.min.js：
   - https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js
   - https://unpkg.com/exceljs@4.4.0/dist/exceljs.min.js

2. 打开 Service Worker 控制台

3. 粘贴以下代码（替换 `PASTE_EXCELJS_CODE_HERE` 为实际内容）：

```javascript
// 读取下载的文件内容，复制全部文本
const excelJSCode = `PASTE_EXCELJS_CODE_HERE`;

// 保存到缓存
chrome.storage.local.set({ excelJSCache: excelJSCode }, () => {
    console.log('✅ ExcelJS已手动缓存，大小:', excelJSCode.length);
    console.log('请重新尝试导出');
});
```

### 方案 B：使用本地文件（开发模式）

如果方案 A 太麻烦，可以将 ExcelJS 文件放到插件目录：

1. 下载 exceljs.min.js 文件
2. 放到插件目录（和 background.js 同级）
3. 修改 manifest.json：

```json
{
  "background": {
    "service_worker": "background.js",
    "type": "module"
  },
  "web_accessible_resources": [{
    "resources": ["exceljs.min.js"],
    "matches": ["<all_urls>"]
  }]
}
```

4. 修改 background.js 的 loadExcelJS 函数
