**您现在必须完成这一步，否则导出功能无法使用！**

#### 方法1：手动下载（推荐）⭐

1. **访问以下任一链接**（选一个网速快的）：
   - https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js
   - https://cdnjs.cloudflare.com/ajax/libs/exceljs/4.4.0/exceljs.min.js

2. **下载文件**：
   - 右键链接 → "目标另存为..." 或 "Save link as..."
   - 保存为：`exceljs.min.js`
   - 文件大小应该约 **950KB**（不是几KB）

3. **放到插件目录**：
   ```
   d:\桌面\稳定版-闲鱼浏览器插件\exceljs.min.js
   ```
   
   **确保文件和 background.js 在同一目录！**

#### 方法2：浏览器直接保存

1. 在浏览器中访问：
   ```
   https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js
   ```

2. 页面会显示一堆 JavaScript 代码

3. 按 `Ctrl+S` 保存页面：
   - 文件名：`exceljs.min.js`
   - 保存类型：选择"所有文件"（不要选"网页"）
   - 保存到：`d:\桌面\稳定版-闲鱼浏览器插件\`

## ❓ 常见问题

### Q1: 下载的文件只有几KB？
**A:** 您可能下载的是 HTML 页面，不是真正的 JS 文件。
- 解决方案：右键链接 → "目标另存为"，不要直接点击链接

### Q2: 找不到下载的文件？
**A:** 检查浏览器的下载文件夹，然后移动到插件目录。

### Q3: 还是导出 CSV？
**A:** 
1. 确认 `exceljs.min.js` 文件存在且大小正确
2. 打开 Service Worker 控制台查看错误日志
3. 将日志截图发给我

### Q4: importScripts is not defined？
**A:** 确保在 Service Worker 环境中运行，不是在网页中。
