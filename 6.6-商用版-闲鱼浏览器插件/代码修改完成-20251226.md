## 🎨 颜色渐变逻辑

### 想要数 - 红色梯度

- **起点：** 500（开始显示颜色）
- **梯度：** 500 → 1000 → 2000 → 5000
- **颜色强度：** 20% → 40% → 60% → 100%

- **起点：** 1%（任何大于0的值都显示颜色）
- **梯度：** 0 → 5% → 10% → 15%
- **颜色强度：** 10% → 25% → 50% → 100%

## 💡 技术细节

### 颜色编码

**想要数 - 红色：**
```javascript
// RGB: (redIntensity, 0, 0)
500-1000:  RGB(51, 0, 0)   → #330000
1000-2000: RGB(102, 0, 0)  → #660000
2000-5000: RGB(153, 0, 0)  → #990000
>5000:     RGB(255, 0, 0)  → #FF0000
```

**询单率 - 绿色：**
```javascript
// RGB: (0, greenIntensity, 0)
0-5%:   RGB(0, 26, 0)   → #001A00
5-10%:  RGB(0, 64, 0)   → #004000
10-15%: RGB(0, 128, 0)  → #008000
>15%:   RGB(0, 255, 0)  → #00FF00
```

### 文字颜色自动调整

- 颜色强度 ≤ 100：黑色文字（浅色背景）
- 颜色强度 > 100：白色文字（深色背景）

确保在任何颜色深度下文字都清晰可读。

## 🐛 如果遇到问题

### 问题1：采集数量还是不对

- 确认已重新加载插件
- 清空浏览器缓存（Ctrl+Shift+Delete）
- 关闭所有闲鱼标签页后重试

- 检查 Service Worker 控制台是否有错误
- 确认 ExcelJS 已成功加载（应该看到 "[ExcelJS] ✅"）

### 问题3：列宽没有变化

- 检查导出的文件是 `.xlsx` 格式（不是 `.csv`）
- CSV 格式不支持列宽设置
