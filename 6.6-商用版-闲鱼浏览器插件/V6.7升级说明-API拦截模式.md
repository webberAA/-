# V6.7 升级说明 - API 拦截模式

## 🎯 核心升级

### 新增技术栈
- **Manifest V3 的 `world: "MAIN"`** - 注入脚本到页面主世界
- **Hook `window.fetch` 和 `XMLHttpRequest`** - 拦截网络请求
- **`response.clone()` 克隆数据流** - 读取响应不影响原始请求
- **`CustomEvent` 跨世界通信** - MAIN 世界 → ISOLATED 世界

---

## ✨ 功能提升

### 1️⃣ 精确的发布时间
**之前 (V6.6)**：从 DOM 解析相对时间，如 "5小时前发布"
```
发布时间: 5小时前发布
```

**现在 (V6.7)**：从 API 获取精确时间戳 `publishTime: "1761200924000"`
```
发布时间: 2025/10/23 15:28
```

### 2️⃣ 精确的想要数
**之前**：从 DOM 解析，可能丢失精度（如 "1.5万"）
**现在**：从 API 获取精确数值 `wantNum: "15234"`

## 📁 修改的文件

### manifest.json
```json
{
  "version": "6.7",
  "content_scripts": [
    {
      "js": ["inject-main.js"],
      "run_at": "document_start",
      "world": "MAIN"  // 🆕 注入到页面主世界
    },
    {
      "js": ["content.js"],
      "world": "ISOLATED"  // 原有的隔离世界
    }
  ]
}
```

### 🆕 inject-main.js
新增文件，运行在 MAIN 世界：
```javascript
// Hook fetch 拦截闲鱼 API
window.fetch = async function(...args) {
    const response = await originalFetch(...args);
    if (url.includes('mtop.taobao.idlemtopsearch.pc.search')) {
        const clonedResponse = response.clone();
        const data = await clonedResponse.json();
        // 提取 publishTime, wantNum 等精确数据
        window.dispatchEvent(new CustomEvent('GOOFISH_API_INTERCEPTED', { detail: apiData }));
    }
    return response;
};
```

### content.js
更新接收 API 数据的逻辑：
```javascript
// 监听 MAIN 世界的数据
window.addEventListener('GOOFISH_API_INTERCEPTED', (event) => {
    const data = event.detail;
    apiDataCache.set(data.itemId, data);
});

// 采集时优先使用 API 数据
if (apiData && apiData.publishTime) {
    publishTimeValue = formatTimestamp(apiData.publishTime);  // 精确时间
}
```

## 🛡️ 安全性说明

### 为什么不会触发反爬虫？
1. **被动拦截**：我们只读取浏览器已发起的请求，不发起额外请求
2. **原生身份**：所有请求使用浏览器的 cookie/token，与正常用户一致
3. **无修改**：使用 `response.clone()` 克隆数据流，不修改原始响应
4. **本地运行**：代码在用户浏览器本地运行，不涉及外部服务器

## 🐛 常见问题

### Q: 控制台没有看到 API 拦截日志？
**A**: 
1. 确认已重新加载插件
2. 检查 `manifest.json` 的 `content_scripts` 是否正确配置了两个条目
3. 尝试刷新页面

### Q: 发布时间仍然是相对时间？
**A**: 
1. API 拦截需要在页面加载时就注入，确保 `run_at: "document_start"`
2. 如果 API 数据未拦截到，会回退到 DOM 解析

### Q: 采集的想要数还是"万"？
**A**: 
1. 检查控制台 `[API数据]` 日志
2. 如果 API 返回的 `wantNum` 本身就是带"万"的字符串，则保持原样
