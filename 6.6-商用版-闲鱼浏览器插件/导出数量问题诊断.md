# 🔍 导出数据数量问题诊断

## 📊 问题描述

**您反馈：**
- 只采集了 30 条数据
- 但导出的 Excel 有 90 条

---

## 🔎 诊断步骤

### 步骤 1：查看 Service Worker 控制台的导出日志

打开 Service Worker 控制台（`chrome://extensions` → 插件 → service worker），查看导出时的日志：

```
[导出] 收到导出请求，数据条数: XX    ← 这里显示多少？
[导出] ========== 开始生成Excel文件 ==========
[导出] 数据条数: XX                  ← 这里显示多少？
```

**关键问题：** 这两个数字是 30 还是 90？

---

### 步骤 2：查看采集日志

在插件弹窗的日志区域，查看：

```
✅ 采集完成！共采集 XX 条数据       ← 这里显示多少？
💾 正在生成Excel文件，共 XX 条数据... ← 这里显示多少？
```

---

### 步骤 3：检查是否有重复数据

打开导出的 Excel 文件，检查：

1. **按"商品链接"列排序**，看是否有重复的链接
2. **按"标题"列排序**，看是否有重复的商品

如果有重复，说明采集过程中同一商品被加入了多次。

---

## 🤔 可能的原因

### 原因 1：采集过程中有重复

**如果Service Worker日志显示：**
```
[导出] 数据条数: 90
```

说明 `collectedData` 数组中确实有 90 条，问题在采集阶段。

**可能情况：**
- 滚动页面时，同一商品被抓取了多次
- 翻页时，前后页有重叠的商品

**解决方法：** 需要在采集时去重。

### 原因 2：多次采集数据累积

**如果之前采集过数据，没有点击"清空"：**
- 第一次采集：30 条
- 第二次采集：30 条
- 第三次采集：30 条
- 总计：90 条

**查看方法：**
在插件弹窗中，查看"已采集"数字（导出按钮上方）

**解决方法：**
- 每次采集前，点击"🗑️ 清空"按钮
- 或修改代码，每次采集前自动清空

### 原因 3：浏览器存储的历史数据

打开浏览器控制台（F12），执行：
```javascript
chrome.storage.local.get(['collectedData'], (result) => {
    console.log('存储的数据条数:', result.collectedData?.length);
    console.log('数据:', result.collectedData);
});
```

查看存储中有多少条数据。

---

## ✅ 快速解决方案

### 方案 A：清空后重新采集（推荐）

1. 点击插件弹窗的 **"🗑️ 清空"** 按钮
2. 重新开始采集
3. 采集完成后立即导出

### 方案 B：手动清除存储

在浏览器控制台执行：
```javascript
chrome.storage.local.set({ collectedData: [] }, () => {
    console.log('已清空数据');
    location.reload();
});
```

### 方案 C：修改代码，自动去重

如果确实是重复数据问题，我可以修改代码添加去重逻辑。

## 🔧 临时解决方法

**如果急需只导出 30 条：**

1. 打开浏览器控制台（F12）
2. 执行以下代码：

```javascript
// 获取当前数据
chrome.storage.local.get(['collectedData'], (result) => {
    let data = result.collectedData || [];
    
    console.log('原始数据条数:', data.length);
    
    // 只保留最后30条
    data = data.slice(-30);
    
    console.log('处理后数据条数:', data.length);
    
    // 保存
    chrome.storage.local.set({ collectedData: data }, () => {
        console.log('已更新，请刷新插件弹窗');
alert('数据已更新为最后30条，请关闭并重新打开插件弹窗，然后导出');
    });
});
```
