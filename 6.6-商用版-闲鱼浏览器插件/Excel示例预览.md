## 💡 如何充分利用条件格式

### 快速筛选技巧

1. **找爆款**（5秒快速扫描）
   - 👀 直接看绿色背景 → 想要数超过1000
   - 👀 同时看红色询单率 → 双倍确认转化好
   - ✅ 这些是最值得关注的商品

2. **找高转化**
   - 👀 看红色询单率 → 转化率超过15%
   - 📊 即使想要数不多，也值得关注
   - 💡 可能是细分市场的好商品

3. **看趋势**
   - 👀 流行程度列的颜色
   - 🔴 红色 → 快速增长，赶紧跟进
   - 🟠 橙色 → 稳步上升，持续观察
   - 🟡 黄色 → 缓慢增长，可以考虑

4. **快速访问**
   - 🔵 点击蓝色链接 → 直接打开商品页
   - 📱 无需复制粘贴 → 提高效率
   - 🚀 批量打开感兴趣的商品

### Excel 进阶技巧

#### 1. 自定义筛选
```
1. 选中表头行
2. 点击"数据" → "筛选"
3. 在"想要"列筛选：数字筛选 > 大于 > 1000
4. 在"询单率"列筛选：数字筛选 > 大于 > 15
```

#### 2. 排序查看
```
1. 选中整个数据区域
2. 点击"数据" → "排序"
3. 按"流行程度数值"降序排列 → 找最热商品
4. 或按"想要数"降序排列 → 找最受欢迎商品
```

#### 3. 创建数据透视表
```
1. 选中数据 → "插入" → "数据透视表"
2. 分析不同价格区间的询单率
3. 统计不同卖家的热门商品数量
4. 对比不同时间段的数据变化
```

## 🎯 使用场景示例

### 场景1：选品调研
```
目标：找到市场热门且转化好的商品类型
步骤：
  1. 导出当天数据
  2. 筛选绿色背景（想要>1000）
  3. 再筛选红色询单率（>15%）
  4. 分析这些商品的共同特点
  5. 确定选品方向
```

### 场景2：竞品分析
```
目标：跟踪竞争对手的商品表现
步骤：
  1. 搜索竞品关键词
  2. 每周导出一次数据
  3. 对比"浏览量增长"和"想要数增长"
  4. 观察流行程度颜色变化
  5. 及时调整自己的策略
```

### 场景3：定价策略
```
目标：找到最优价格区间
步骤：
  1. 导出不同价格区间的商品
  2. 对比询单率（红色高亮的比例）
  3. 分析想要数（绿色高亮的分布）
  4. 找到转化率最高的价格带
  5. 优化自己的定价
```

## ⚙️ 自定义设置

如果您想修改条件格式的阈值，可以编辑 `background.js` 文件：

### 修改询单率阈值（默认15%）
```javascript
// 第618行附近
if (!isNaN(询单率数字) && 询单率数字 > 15) {  // 改成 > 20 表示20%以上才高亮
```

### 修改想要数阈值（默认1000）
```javascript
// 第645行附近
if (想要数字 > 1000) {  // 改成 > 500 表示500以上就高亮
```

### 修改流行程度阈值
```javascript
// 第691-720行附近
if (流行程度数值 > 5) { ... }     // 爆火（改成 > 8 提高标准）
if (流行程度数值 > 2) { ... }     // 上升（改成 > 3）
if (流行程度数值 > 0.5) { ... }   // 增长（改成 > 1）
```

### 修改颜色
```javascript
// ARGB 格式：FF + 6位颜色代码
fgColor: { argb: 'FFFF0000' }  // 红色
fgColor: { argb: 'FF00AA00' }  // 绿色
fgColor: { argb: 'FFFF6600' }  // 橙色
fgColor: { argb: 'FFFFFF00' }  // 黄色
fgColor: { argb: 'FF0000FF' }  // 蓝色

// 常用颜色代码
// FF0000 - 纯红
// 00FF00 - 纯绿
// 0000FF - 纯蓝
// FFFF00 - 纯黄
// FF00FF - 紫色
// 00FFFF - 青色
// FFA500 - 橙色
// 800080 - 紫色
```
