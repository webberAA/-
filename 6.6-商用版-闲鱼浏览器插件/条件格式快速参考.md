# 🎯 条件格式快速参考

## 导出文件格式
✅ `.xlsx` (真正的 Excel 格式)

## 自动条件格式一览

| 列名 | 条件 | 背景色 | 文字色 | 说明 |
|------|------|--------|--------|------|
| **询单率** | > 15% | 🔴 红色 | ⚪ 白色 | 高转化率商品 |
| **想要数** | > 1000 | 🟢 绿色 | ⚪ 白色 | 超热门商品 ⭐新增 |
| **流行/热度** | 所有行 | 🟠 橙色 | ⚪ 白色 | 热度等级显示 |
| **流行程度** | 数值 > 5 | 🔴 红色 | ⚪ 白色 | 爆火/热门 |
| **流行程度** | 数值 > 2 | 🟠 橙色 | ⚪ 白色 | 上升趋势 |
| **流行程度** | 数值 > 0.5 | 🟡 黄色 | ⚫ 黑色 | 稳定增长 |
| **商品链接** | 所有链接 | 无 | 🔵 蓝色 | 可点击超链接 |

## 使用技巧

### 📌 快速筛选策略

**找爆款商品：**
```
1. 看绿色背景（想要数>1000）
2. 看红色流行程度（增长快）
3. 看红色询单率（转化高）
```

**找潜力商品：**
```
1. 看橙色流行程度（趋势上升）
2. 看询单率（转化潜力）
3. 对比浏览量增长
```

**监控商品变化：**
```
1. 定期导出（每天/每周）
2. 对比"浏览量增长"和"想要数增长"
3. 关注流行程度的颜色变化
```

### 🔍 Excel 筛选功能

利用 Excel 的筛选功能：

1. **筛选热门商品**
   - 点击"想要数"列的筛选按钮
   - 选择"数字筛选" > "大于" > 输入 1000

2. **筛选高转化商品**
   - 点击"询单率"列的筛选按钮
   - 选择"数字筛选" > "大于" > 输入 15

3. **排序功能**
   - 按"流行程度数值"降序排列，找最热商品
   - 按"想要数增长"降序排列，找增长最快的商品

## ⚠️ 注意事项

1. **确保导出 Excel 格式**
   - 文件扩展名必须是 `.xlsx`
   - 如果是 `.csv`，说明 ExcelJS 加载失败
   - 检查网络连接后重试

2. **条件格式在 CSV 中无效**
   - CSV 只是纯文本文件
   - 必须是 Excel 格式才能看到颜色

3. **兼容性**
   - Microsoft Excel ✅
   - WPS Office ✅
   - Google Sheets ✅
   - LibreOffice Calc ✅

4. **历史数据**
   - 自动保存最近 1000 条记录
   - 用于计算流行程度
   - 存储在浏览器本地

## 🎨 自定义修改

如需修改条件格式阈值，编辑 `background.js` 文件：

```javascript
// 询单率阈值（当前 > 15%）
if (询单率数字 > 15) { ... }

// 想要数阈值（当前 > 1000）
if (想要数字 > 1000) { ... }

// 流行程度阈值
if (流行程度数值 > 5) { ... }  // 爆火
if (流行程度数值 > 2) { ... }  // 上升
if (流行程度数值 > 0.5) { ... } // 增长
```

颜色代码（ARGB 格式）：
- 红色：`FF0000`
- 绿色：`00AA00`
- 橙色：`FF6600` 或 `FF8800`
- 黄色：`FFFF00`
- 蓝色：`0000FF`
